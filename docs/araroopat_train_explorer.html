after training

Compose any id sequence — the way a language model would emit it — and it goes straight into AraRooPatTokenizer.decode() of the instance built above. Nothing is validated for "grammar": orphan roots, a [PAT_*] with no root, an unclosed literal, a leading enclitic, special tokens mid-stream, ids that are not in the vocab, and (ROOT, PAT) pairs the corpus never contained (→ CAMeL generator, tier 2) are all fair game.

The output-so-far column is decode(ids[:k]) for every prefix — the ground truth of what a consumer sees as tokens arrive. The annotation column is an interpretation derived from the token family; it never feeds the output.

The real encode() of any text on this tokenizer. Every alpha chunk is classified by the path it took — the exact all-or-nothing rule of _emit_alpha — and can be expanded to see the whole process: CAMeL's candidates and every gate, the clitic peeler, the vocab / budget check, the emitted tokens. Digits, punctuation and Latin go through fixed inventories or UNK and are not listed.
